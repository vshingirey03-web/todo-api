# todo-api

Сервер для списка дел: регистрация и вход, задачи с подпунктами.

## Стек

- Node.js 24 и Express 5
- База данных SQLite (встроенный модуль `node:sqlite`), файл `tasks.db`
- Хостинг: Render (бесплатный тариф: файл базы стирается при перезапуске)

## Команды

- Локальный запуск: `npm run dev` (читает настройки из `.env`)
- Запуск на хостинге: `npm start`
- Проверка синтаксиса: `node --check server.js`

## Правила

- Настройки (порт, лимиты) берутся из `.env`; сам файл `.env` в Git не добавляем, образец лежит в `.env.example`.
- Значения от пользователя в SQL подставляем только через `?`, никогда не склеиваем строкой.
- Пароли храним только в виде хэша с солью (`scrypt`), открытым текстом их не сохраняем и не выводим в логи.
- Все маршруты с задачами защищены проверкой токена (`auth`); пользователь видит и меняет только свои задачи.

## Чего не делать

- Не коммитить `.env` и `tasks.db`: в них настройки и данные пользователей, в Git они не нужны.
- Не добавлять новые библиотеки без необходимости.

## Как проверять изменения

После правки запустить сервер и проверить регистрацию, вход, добавление, правку и удаление задач; затем сохранить в Git.
